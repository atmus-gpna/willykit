# Button

Компонент инпута

#### Пример

<Canvas of={Input} />

### Применение

```ts
import {Input} from "willykit";

const Example = () => {
  return (
      <Input
        used="modal"
        multiline
        error
        disabled
        readOnly,
        width: 400,
        height: 200,
        placeholder={"Введите текст"}
      />
  );
};

export default Example;
```

#### Аргументы

- **used** - Показывает область использования компонента: в модальном окне (modal) или в заголовке окна (header);
- **placeholder** - Показывает заполняющий пустой Input текст;
- **error** - Показывает наличие ошибки в данном поле (сопровождается соответствующей окраской обводки-border'а);
- **errorText** - Показывает текст ошибки у данного поля;
- **readOnly** - Показывает, что поле только для чтения;
- **disabled** - Показывает, что пользователь никак не может взаимодействовать с данным полем (сопровождается соответствующей окраской поля);
- **value** - Значение поля;
- **onChange** - Вызов функции при изменении значения в компоненте Input;
- **autoComplete** - Эта функция помогает пользователям быстрее заполнять формы;
- **autoFocus** - Автоматическое помещение курсора при первом рендере;
- **fullWidth** - Заполнение всей ширины страницы;
- **width** - Ширина компонента;
- **height** - Высота компонента;
- **multiline** - Использование textarea;
- **inputRef** - Передача ссылки на React-компонент Input;
- **startAdornment** - Для расположения ноды в левой части компонента Input;
- **endAdornment** - Для расположения иконок в правой части компонента Input;
- **className** - Для создания пользовательского класса стилей;
- **type** - Тип инпута ("password", "text" и тд.);
