# Icon

Компонент иконки

#### Пример

<Canvas of={Icon.SingleIcon} />

### Применение

```ts
import {Icon} from "willykit";

const DocsIcon = () => {
  return (
      <Icon
        name= {"pluse"},
        color= {"red"},
        width= {"24"},
      />
  );
};

export default DocsIcon;
```

#### Аргументы

- **name** - Название из перечня.
- **color** - Цвет.
- **width** - Размер иконки в пикселях.
