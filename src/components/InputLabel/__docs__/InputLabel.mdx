# InputLabel

#### Пример

```ts
import {InputLabel} from "willykit";

const Example = () => {
  return (
      <InputLabel 
        tooltip="Текст"
        required        
        >
            Текст метки
        </InputLabel>
  );
};

export default Example;
```

#### Аргументы

- **component** - Тип родительского компонента "input" | "fieldset"
- **label** - Передаваемый текст;
- **tooltip** - Появляется Tooltip c всплывающей подсказкой;
- **required** - Отображает символ *;
